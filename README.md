# Khusboo Entertainment - Outdoor Advertising Agency Website

A modern, responsive, high-performance web platform built for **Khusboo Entertainment** — premier outdoor media and advertising agency based in Raipur, Chhattisgarh.

## 🚀 Live Preview & Deployment via GitHub Pages
To enable the free live preview on GitHub Pages:
1. Go to your repository on GitHub.
2. Click **Settings** > **Pages** (in the left sidebar).
3. Under **Build and deployment** > **Branch**, select `main` and `/ (root)`, then click **Save**.
4. Within 1–2 minutes, your live website preview will be active at:
   `https://<your-username>.github.io/<repo-name>/`

## ✨ Features & Highlights
- **Ultra-Modern Obsidian & Electric Glow Theme**: Built with glassmorphism, fluid responsive typography (Outfit & Plus Jakarta Sans), and electric neon/amber accents.
- **Dynamic Hero Slider**: Automatic transition across prime billboard showcases with live trust metrics (250+ Prime Sites, 10M+ Daily Commuters, 15+ Years Leadership, 98% Retention).
- **Interactive OOH Campaign Estimator (Calculator)**: Real-time media planner calculating citizen reach, impressions, package tier, and 1-click WhatsApp quote generator.
- **Full Photorealistic Portfolio**: 6 real delivered campaign showcases with interactive filter tabs (All, LED Billboards, Highway Unipoles, Mobile Vans, Audio-Video & Jingles).
- **Official Clientele Marquee**: Infinite CSS marquee showcasing Chhattisgarh Samvad, CG Women & Child Development, CG DPR, CG Social Welfare, Nakoda Group, and ASG Eye Hospital.
- **Complete Booking Desk & Direct Contact**: Replaced old placeholders with full Raipur HQ contact info, operating hours, direct phone/WhatsApp triggers, Google Map embed, and interactive inquiry form.
- **100% Mobile Responsive**: Fluid CSS clamp scaling for icons, text, and buttons. Single-line navbar on all mobile screens with slide-out drawer menu and floating bottom quick-action bar.
- **Dual Server Support**: Native HTML5/CSS3/JS for static hosting (GitHub Pages, Vercel, Netlify) + PHP bridges & `.htaccess` for Apache/cPanel/Hostinger servers with zero 404s.
